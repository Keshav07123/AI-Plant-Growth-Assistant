# 🌿 AI Plant Disease Detection App

A Flutter-based mobile application designed to identify plant diseases using AI-powered models and provide actionable insights for better crop health management.

## 🚀 Overview

This project aims to assist farmers and plant enthusiasts by enabling quick and accurate detection of plant diseases through image-based analysis. The application integrates a user-friendly Flutter frontend with a Python-based backend powered by deep learning models.

## 📱 Features

* 🌱 Plant selection and tracking
* 📸 Image upload for disease detection
* 🤖 AI-based prediction using trained CNN models
* 📊 Confidence score for predictions
* 💡 Suggested treatments and preventive measures
* 🧘 Additional wellness feature with short relaxation exercises

## 🛠️ Tech Stack

* **Frontend:** Flutter
* **Backend:** Python (Flask/FastAPI)
* **AI Models:** CNN (.pt models)
* **Other Tools:** REST APIs, JSON

## 🔗 How It Works

1. User selects or inputs plant details
2. Uploads plant image
3. Image is sent to backend API
4. AI model processes the image
5. Result (disease + solution) is displayed in the app

## 📂 Project Structure

* `lib/` → Flutter UI and logic
* `assets/` → Images and resources
* `pubspec.yaml` → Project dependencies

## ⚙️ Setup Instructions

1. Clone the repository
2. Run `flutter pub get`
3. Connect backend API URL
4. Run the app using `flutter run`
